# mySWOT

**通过追问、获准读取的个人笔记和可靠外部资讯，帮助你发现遗漏条件、形成选项，并自己作出决定。**

[English overview](README.md) · [虚构示例](examples/career-decision.md) · [评测方案](evals/README.md)

适用于职业选择、学业安排、个人发展和项目决策。默认使用中文。

## 为什么使用

有些优势因为太习以为常而想不起来，有些限制只是过去的自我评价；看起来诱人的外部机会，也可能存在尚未核实的条件。mySWOT 用逐轮追问帮助你说具体，再用资料补充和检验。

- S/W/O/T 分别尽量探索 2–3 轮，每轮 2–3 问，听完回答才继续。
- 在本人明确许可后，从可用的 flomo、Notion、文档或本地笔记中寻找候选 S/W 线索，并请本人确认。
- 在 O/T 首轮自述后检索外部信息，附来源、时间和适用范围，核对是否应纳入分析。
- 将确认的条件组合为行动选项，展示取舍，不自行推荐排名。

没有个人知识库也能使用。连接器能力取决于运行环境；本项目不自带跨平台数据连接器。

## 开始使用

从 [Hanaaa-Sying/mySWOT](https://github.com/Hanaaa-Sying/mySWOT) 下载或克隆：

```sh
git clone https://github.com/Hanaaa-Sying/mySWOT.git
```

将 [`skills/myswot`](skills/myswot/SKILL.md) 整个文件夹放入所用助手支持的 skill 目录，保留 `SKILL.md`、`references` 和 `agents` 的结构。已有同名版本时先比较，不直接覆盖。

Codex 项目级安装可将 `skills/myswot` 复制到目标项目的 `.agents/skills/myswot`。已于 2026-11-18 实测公开版可从该位置加载为已启用的项目级 skill，无加载错误。调用示例：

```text
请用 $myswot 帮我理清：我应该继续深造还是先工作？
先通过追问了解我的情况；如果需要查看个人笔记，请先询问读取范围。
```

完整探索通常包含四维合计 8–12 轮实质追问，另有开场及总结；这不是固定时长承诺。可以随时要求跳过或总结，输出会注明未充分覆盖的部分。

## 个人资料怎样使用

先自主回想，再决定是否授权检索。授权会明确来源、主题或文件范围、时间范围、排除内容；连接服务本身不等于同意读取。

AI 从资料中找到的内容会标为候选线索，展示日期、出处和其他可能解释，再由本人确认。不会把读书摘录当成本人经历、把一次失败当成固定劣势，也不会把没有笔记等同于没有能力。

默认只读、不写回、不建立永久画像，不把私人笔记原文用于公开网络搜索。这些是对宿主助手的行为指令；实际权限、数据保留和连接器行为仍由所用平台决定。
